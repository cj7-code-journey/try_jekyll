# Try Jekyll: The Master Guide 🚀

Welcome to the source code of the **Jekyll Master Guide**! This project is a step-by-step tutorial series designed to help beginners build, customize, and deploy a fast, secure, and free static blog using Jekyll and GitHub Pages.

🌐 **[Click here to view the Live Website](https://cj7-code-journey.github.io/try_jekyll/)**

## 🛠️ Tech Stack Used
* **Ruby & Jekyll:** For static site generation.
* **Markdown:** For content creation.
* **GitHub Pages:** For free, continuous deployment.
* **Minima Theme:** Customized with layout overrides for pagination.

## 💻 How to run this locally
If you want to clone this repository and run it on your own machine:
1. Ensure you have Ruby and Jekyll installed.
2. Clone this repo: `git clone https://github.com/cj7-code-journey/try_jekyll.git`
3. Navigate into the folder: `cd try_jekyll`
4. Run the local server: `bundle exec jekyll serve`
5. Open `http://localhost:4000` in your browser.
